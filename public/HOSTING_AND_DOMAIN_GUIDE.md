# 🌐 HaiderSanitary POS & Website - Hosting & Custom Domain Guide
# ہوسٹنگ اور کسٹم ڈومین (URL) لگانے کی مکمل گائیڈ

---

## 🌟 ۱. مفت اور تیز ترین ہوسٹنگ کے ۳ بہترین طریقے (Top 3 Free Hosting Platforms)

آپ کی ایپ اور ویب سائٹ کے لیے ہوسٹنگ کی فائلیں (`vercel.json`, `netlify.toml`, `dist/`) ۱۰۰ فیصد تیار ہیں۔ آپ بغیر کسی ماہانہ خرچے کے تاحیات فری چلا سکتے ہیں:

---

### طریقہ نمبر ۱: Vercel (سب سے تیز اور سب سے آسان - ۲ منٹ میں لائیو) ⚡
1. ویب سائٹ کھولیں: **[vercel.com](https://vercel.com)**
2. اپنے گوگل اکاؤنٹ (Gmail) یا GitHub سے فری سائن اپ کریں۔
3. **"Add New Project"** دبائیں اور اپنا GitHub ریپوزٹری سلیکٹ کریں یا سورس کوڈ زپ فائل کو امپورٹ کریں۔
4. **Deploy** بٹن دبائیں!
5. آپ کو فوراً ایک لائیو اور محفوظ URL مل جائے گا، جیسے:
   `https://haidersanitary.vercel.app`

---

### طریقہ نمبر ۲: Netlify (ڈریگ اینڈ ڈراپ - بغیر کسی کوڈ کے ۱ منٹ میں لائیو) 🚀
1. ویب سائٹ کھولیں: **[netlify.com](https://netlify.com)**
2. فری اکاؤنٹ بنائیں۔
3. `dist` فولڈر کو اٹھا کر نیٹلی فائی کی سکرین پر **Drag & Drop** کر دیں۔
4. آپ کی ویب سائٹ فوراً لائیو ہو جائے گی:
   `https://haider-sanitary.netlify.app`

---

### طریقہ نمبر ۳: کلاؤڈ رن (Google Cloud Run - جو ابھی چل رہا ہے) ☁️
- یہ پروجیکٹ ابھی بھی گوگل کلاؤڈ رن پر 24/7 لائیو اور پروڈکشن میں چل رہا ہے۔

---

## 🏷️ ۲. اپنی کسٹم ڈومین (URL) کیسے لگائیں؟ (How to Connect Custom Domain)
جیسے: `www.haidersanitary.com` یا `haidersanitary.pk`

1. **ڈومین خریدیں:** Namecheap, GoDaddy یا PKNIC سے اپنی ڈومین (مثلاً `haidersanitary.com`) خرید لیں۔
2. **Vercel / Netlify میں جائیں:**
   - **Settings ➔ Domains ➔ Add Domain** پر کلک کریں۔
   - اپنی ڈومین کا نام درج کریں: `haidersanitary.com`
3. **DNS Records سیٹ کریں:**
   - اپنے ڈومین پرووائیڈر میں جا کر یہ ۲ ریکارڈز درج کریں:
     - **Type:** `CNAME` | **Name:** `www` | **Value:** `cname.vercel-dns.com`
     - **Type:** `A` | **Name:** `@` | **Value:** `76.76.21.21`
4. **مبارک ہو!** آپ کا اسٹور اب `https://www.haidersanitary.com` پر لائیو ہو جائے گا اور SSL سرٹیفکیٹ (سبز تالا 🔒) خود بخود لگ جائے گا۔

---

## 🛡️ ۳. زیرو ڈیٹا لاس اور آف لائن سپورٹ
- ویب سائٹ اور پی او ایس کلاؤڈ پر ہوسٹ ہونے کے باوجود فون میں آف لائن کام کرے گی۔
- ڈیٹا ہمیشہ فون کے لوکل اسٹوریج میں محفوظ رہے گا۔
